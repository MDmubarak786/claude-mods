# Getting help

| You want to | Go to |
| :-- | :-- |
| Ask how to use a mod, or which mod fits a problem | [Discussions](https://github.com/MDmubarak786/claude-mods/discussions) |
| Report a mod that does the wrong thing | A [bug report](https://github.com/MDmubarak786/claude-mods/issues/new?template=01-bug.yml) |
| Suggest a change to a mod | An [improvement request](https://github.com/MDmubarak786/claude-mods/issues/new?template=02-mod-improvement.yml) |
| Propose a new mod | A [mod idea](https://github.com/MDmubarak786/claude-mods/issues/new?template=03-mod-idea.yml) |
| Report a mod that reads, runs, or sends something it shouldn't | A [private security report](https://github.com/MDmubarak786/claude-mods/security/advisories/new), never a public issue |
| Learn how mods work | The [Claude Code mods documentation](https://code.claude.com/docs/en/plugins/mods/overview) |

Before you file a bug, run `/plugin marketplace update modhub` and `/reload-plugins` so you're on the latest version, and check that `/plugin` lists the mod on its mods line.

This is a community project with no paid support. Maintainers answer as they can; a clear reproduction gets the fastest reply.
